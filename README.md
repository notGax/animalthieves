# The Crooked Mile

A 1–4 player co-op heist game built in **Godot 4.7**. Play as a crew of round slime thieves working the strip: rob Rat Mart, dodge the guards, drag your loot to the van, and reinvest the take in tools, vehicles, and production machines — then work your way up the street to bigger stores and bigger bosses.

The game runs on a server-authoritative multiplayer foundation (sessions, chat, player list, synchronized state) with all heist gameplay layered on top: movement tuned for weight and momentum, tool-based thievery, drivable vehicles, form transformations, and a persistent campaign.

## Key Features

- **Online co-op for up to 4 players:** host or join a session, run multiple local instances for testing, or play against a headless dedicated server. Server-validated interactions, travel, purchases, and progression.
- **Round slime characters:** every thief is a slime — squashy movement with coyote time, jump buffering, and variable jump height; sprint with no stamina; switchable first- and third-person views.
- **Tool-based heisting:** grapple hook (distance-scaled pull), water gun (heal teammates, douse fires, stun guards), slime crystal (revive downed crew), and jetpack.
- **Drivable vehicles:** shopping cart, mini truck, and racecar with per-vehicle handling profiles, arcade grip, speed-dependent steering, server-side curb assist, and ramming as discrete impact events.
- **Transformations:** spend form cooldowns to become a rat, boar, bird, or lizard — each form changes speed, size, and how you move through the level.
- **Guards with reads:** patrolling species guards (rat, boar, magpie, lizard) with bribing, stunning, bait, and alarms — plus the Big Cheese in the basement kitchen and a mecha dragon at the end of the road.
- **Persistent campaign:** cash, bank, recovered recipes, installed production machines, gear, crystals, and wins survive session restarts (host-side JSON save).
- **Fully synthesized audio:** every sound — one-shots, spatialized world events, seamless ambience loops, per-vehicle engine hums — is generated at runtime in GDScript. The repo contains no audio files and no licensed sound assets.
- **Deterministic world generation:** the entire Rat Mart level (and its four merchandise scenes) is generated by a Python script; rerunning it produces a byte-identical scene file.

## How to Run the Project

1. **Clone or download** the repository.
2. **Open in Godot Engine** 4.7 or newer (Forward Plus renderer).
3. **Press** <kbd>F5</kbd> or click `Run Project`.

For local multiplayer testing, open `Debug > Customize Run Instances`, enable `Enable Multiple Instances`, choose the desired number of instances, and run the project.

## Dedicated Server

From the project directory, start a headless server with:

```bash
godot --headless --path .
```

Then start another project instance, choose `Join`, and connect to `127.0.0.1`. The server listens on UDP port `8080`. Press <kbd>Ctrl</kbd>+<kbd>C</kbd> in the server terminal to stop it.

On Linux or macOS, the provided wrapper can also locate the Godot executable and handle shutdown:

```bash
./run_headless_server.sh
```

Ensure the script has execution permissions (`chmod +x run_headless_server.sh`) and that the `godot` binary is in your system `PATH`. If Godot is installed under another command or path, set `GODOT_BIN`:

```bash
GODOT_BIN=/path/to/godot ./run_headless_server.sh
```

## Controls

### Movement
- <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> to move (camera-relative).
- <kbd>Shift</kbd> to sprint (no stamina).
- <kbd>Space</kbd> to jump — a single jump with a short coyote window and input buffering.
- <kbd>V</kbd> to switch between first-person and third-person views.

### Thievery
- <kbd>G</kbd> to grab or drop merchandise and props.
- Left mouse button to slap, or throw what you are carrying.
- Right mouse button to use the equipped tool.
- <kbd>Q</kbd> to cycle tools (grapple, water gun, slime crystal, jetpack).
- <kbd>X</kbd> to snap back to slime form instantly (skips the transform cooldown).
- <kbd>B</kbd> to place bait. <kbd>H</kbd> to eat. <kbd>C</kbd> to feed a teammate.
- <kbd>R</kbd> to transform (form cooldown applies).

### Interaction and UI
- <kbd>F</kbd> for context interactions: manholes, the trader, machines, vehicles, and markers.
- <kbd>Tab</kbd> (hold) to show the online player list.
- <kbd>T</kbd> to hide/show chat. <kbd>I</kbd> to toggle inventory. <kbd>Esc</kbd> to pause.
- <kbd>F1</kbd> adds a random test item and <kbd>F2</kbd> prints the inventory (debug, host only).

## The Heist Loop

Rob Rat Mart: grab merchandise off the shelves, avoid or misdirect the guards, and haul your loot out to sell. Spend the take at the trader on tools, vehicles, and production machines. Defeat the Big Cheese in the basement kitchen to recover the Rotten Cheese recipe and open the east road, then raid the expansion stores (Boar Hardware, Bird Seed & Co., Cold Blood Electronics). Install machines in The Undercut hideout for passive income, collect at the terminal, and — when the street is yours — take down the mecha dragon.

## Project Structure

- `assets/`: textures, shaders, the vehicle atlas, and third-party asset attribution files.
- `scenes/items/heist/`: the four physics merchandise scenes (cheese, moonshine, canned food, stolen goods).
- `scenes/level/`: the hand-maintained `level.tscn` (menus, players, UI) and the **generated** `heist_world.tscn`.
- `scenes/props/`: authored hero prop scenes the generator instantiates (checkout counter, endcap, fridge, still, recipe vault, hanging lamp).
- `scenes/ui/`: menus, chat, player list, and inventory scenes.
- `scripts/autoload/`: global `Network` and `ItemDatabase` singletons.
- `scripts/audio/`: `game_audio.gd` — runtime audio synthesis, ambience anchors, and playback layers.
- `scripts/heist/`: character presentation (slime, forms, guards, first-person hands).
- `scripts/level/`: session and world coordination, vehicle profiles, store motion, and `build_heist_world.py`.
- `scripts/player/`: player controller, camera rig, and movement feel.
- `scripts/tests/`: the `verify_heist.gd` validation suite.
- `scripts/vehicles/`: the code-built vehicle rig (wheels, suspension, engine audio hooks).
- `scripts/visuals/`: palette, character materials, vehicle materials, HUD widgets, and world effects.
- `tools/`: `build_vehicle_atlas.py`, the deterministic vehicle texture-atlas generator.

## Generated Assets

Two files in this repo are produced by deterministic generators — never hand-edit their outputs:

```bash
python scripts/level/build_heist_world.py   # -> scenes/level/heist_world.tscn + 4 merchandise scenes
python tools/build_vehicle_atlas.py         # -> assets/vehicles/vehicle_atlas.png
```

Both are seeded and rerun byte-identical. All world geometry, lighting, dressing, and audio-emitter placement live in the generator script, not in the scene file.

## Testing

The project ships with a 125-check validation suite covering movement physics, vehicle behavior, multiplayer sync, world generation invariants, tool behavior, and audio:

```bash
# Full suite (exit code 0 = all checks pass)
godot --headless --path . --script res://scripts/tests/verify_heist.gd

# Multiplayer validation: one suite run as the server, then up to 4 clients
godot --headless --path . --script res://scripts/tests/verify_heist.gd -- --server
godot --headless --path . --script res://scripts/tests/verify_heist.gd -- --client --slot=0

# Rendered screenshot capture (writes screenshots/heist_*.png)
godot --path . --script res://scripts/tests/verify_heist.gd -- --capture
```
